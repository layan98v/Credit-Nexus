CREDIT NEXUS

Setup guide for non-technical users · about 5 minutes the first time

1. What this is

You type a company name. The tool pulls that company's real financial statements from the internet, then calculates a credit score, a stress test, the chance of default, and warning flags. An AI then writes short commentary — anything written by AI is marked “AI — verify”.
In plain words: it is a small website that runs only on your own computer. Nothing is uploaded except the questions sent to the AI service you choose.

2. Pick how to open it

A. Website link (if someone shared one) — just open it. Nothing to install. Skip to section 4.
B. Desktop app — one file called CreditNexus.exe (Mac/Linux: CreditNexus).
  1. Save it anywhere, e.g. your Desktop.
  2. Double-click it.
  3. A black window opens; after ~10 seconds your browser opens the dashboard.
Nothing else to install — Python and everything it needs are packed inside the file.
Windows may show “Windows protected your PC”. Click More info → Run anyway. This appears for any new program that isn't signed with a paid certificate. On Mac: right-click the file → Open → Open.
Why a black window? It is the engine that serves the dashboard to your browser. Keep it open while you use the tool; close it to stop.
C. From source (only if you were given the folder, not the file): install Python from python.org ticking “Add python.exe to PATH”, unzip the folder, double-click START.bat (Mac/Linux: bash start.sh).

3. Who makes the app file / website?

Whoever shares the tool does this once (details in README.md): put the folder on GitHub, and GitHub builds the Windows/Mac/Linux app files automatically; connect the same folder to Render (free) for the website link. Everyone else just uses the file or the link.

4. No setup needed

There is no account, password or key to enter. The AI part uses Pollinations' free service, which needs no signup.
Why does the AI part take 30–90 seconds? The free AI service answers one request every 30 seconds. The tool asks it once per company and fills all AI sections from that one answer. Everything based on real data (numbers, score, stress test, warnings) appears straight away.

5. Using it

  1. Type a company or ticker, e.g. TCS, Reliance Industries, AAPL, HSBA.L. Covers US, UK and Indian companies: London tickers end in .L, India .NS, US tickers have no ending. Use the market menu next to the search box to restrict matches. The bar under the header shows what your search matched — e.g. “hsbc” → HSBA.L · HSBC Holdings plc — and lets you switch to the company's other listings.
  2. Click ANALYZE. Numbers, score and warnings appear within 10–40 seconds; the AI sections (Credit commentary, Outlook, Debt notes, Risk, Industry, Governance, Peers, news sentiment) fill in about 30–90 seconds after that, from a single AI request.
  3. Use the tabs: Overview, Financials, Ratios, Credit, Stress, Warnings, Outlook, Debt, Shareholding, Team, Comps, Risk, Industry, News.
The grey bar under the header shows which sources answered (green) and which failed (orange). Amounts are in the company's own reporting currency (Indian companies in ₹ Crore).

6. Every day after

Desktop app: double-click the file. Website: open the link. Close the black window when finished (app only).

7. If something goes wrong

First, always: click Health (top right of the dashboard) → Auto-repair. It installs missing parts and tells you in plain words what is still wrong.
You seeDo this
Website takes ~1 minute to loadFree hosting sleeps when unused; it wakes on the first visit.
“Python not found” (option C only)Reinstall Python with “Add python.exe to PATH” ticked — or use the app file instead.
Browser says “can't reach this page”The black window was closed or is still starting. Wait 10 s and refresh; otherwise double-click START.bat again.
“Yahoo Finance could not be reached”Office networks sometimes block it. Try home Wi-Fi or ask IT to allow *.finance.yahoo.com.
“was not found on Yahoo Finance”Type the exact ticker, e.g. TATAMOTORS.NS.
“Free AI is busy” or AI sections emptyWait 30–60 seconds and press Retry. Data, scores and warnings still work.
The black window also restarts the tool by itself if it crashes — you'll see a line starting with “!!”.

8. Remove it

Delete the app file (or the credit-nexus folder). Website: nothing to remove.
